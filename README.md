# Smart Football AI v0.3

Mobile-first football PWA for Samsung/Android. Favorites, team lookup, TheSportsDB fixtures, Qatar kickoff times, authorized MP4 player.

## Publish with GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Limitations
Public provider may have missing teams/events or browser CORS limitations. No guaranteed live scores, background monitoring, notification scheduling, automatic streaming source switching, DRM bypass or subscription access. GitHub Pages is static hosting.
